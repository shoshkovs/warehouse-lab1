Лабораторная работа 1

Система управления складом на C++17

Для сборки нужны CMake и компилятор C++

Запуск меню

```sh
./start
```

Запуск тестов

```sh
./start test
```

Пять сценариев из задания

```sh
./start demo
```

В меню можно добавлять и удалять товары искать их менять цену и количество
Также можно переносить товар и копировать склад
Сначала нужно ввести вместимость двух складов
Пункт 7 переключает склад а пункт 8 копирует текущий во второй
При копировании содержимое второго склада заменяется после подтверждения
После выхода данные не сохраняются

include содержит заголовки классов
src содержит реализацию и меню
tests содержит проверки по заданию
docs содержит отчет и диаграмму
